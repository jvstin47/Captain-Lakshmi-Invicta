# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

As an open-source static interactive monograph, this project does not process user credentials or store server-side databases. However, security and integrity in web dependencies and build pipelines are taken seriously.

If you discover a potential security vulnerability (such as supply-chain vulnerabilities in dependencies, Cross-Site Scripting (XSS) vectors, or resource exhaustion bugs in the canvas rendering engine), please report it responsibly:

1. **Do not create a public GitHub issue.**
2. Send an email with reproduction steps and vulnerability details to the repository maintainer via GitHub profile contact.
3. You will receive an initial response within 48 hours.
4. An advisory and patch will be released upon validation.

Thank you for helping keep the digital historical commons safe.
